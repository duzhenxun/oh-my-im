# 模块边界

| 模块 | 职责 |
| --- | --- |
| `cli.ts` | `oh-my-im` 命令入口，调用单聊应用。 |
| `omi.ts` | 后台启动、停止、状态与更新；管理机器人和监听器子进程。 |
| `omi-bot.ts` | 从用户级仪表盘配置构造单聊机器人配置并持有进程锁。 |
| `index.ts` | 机器人消息的命令处理、白名单、会话串行化和回复编排。 |
| `dingtalk.ts` | Stream SDK 封装、消息/附件解析、下载和机器人回复。 |
| `dws-listener.ts` | DWS 消费、轮询、规则过滤、批处理、卡片/回复历史/仪表盘集成。 |
| `dws-dashboard.ts` | 本地 HTTP API 与内嵌管理页面。 |
| `monitor-command.ts` | 受限用户的启动/停止监听规则意图解析和纯配置变换。 |
| `codex.ts` | `codex exec` 子进程、JSONL 解码、超时、会话提取和回调。 |
| `dingtalk-card.ts` | DingTalk 互动卡片 API 与 access token 缓存。 |
| `config.ts`、`logger.ts` | 单聊配置装载与日志抽象。 |

测试目前覆盖仪表盘配置保存和监控命令的纯逻辑（`tests/*.test.mjs`）。它们不覆盖外部 Stream、DWS、卡片 API 或真实 Codex 运行。
