# 入口与运行模式

`package.json` 暴露 `omi`（`dist/omi.js`）与 `oh-my-im`（`dist/cli.js`）两个可执行入口。README 将日常运行引导至 `omi`。

- `omi`、`omi start`、`omi listen`：管理器以 listen 模式后台启动 DWS 监听器和单聊机器人。
- `omi --no-listen`：以 bot 模式只启动单聊机器人。
- `omi status`、`stop`、`update`：读取/更新 `~/.oh-my-im/omi-state.json`，并管理自身启动的 PID；代码还检测未受管理的 DWS 监听锁以避免重复运行。

管理器从构建产物目录启动 `dws-listener.js` 与 `omi-bot.js`，把工作目录写入状态用于 `update` 重启。它将 stdout/stderr 追加到用户级 `omi.log`。这说明 `npm run build` 是运行 `omi` 的前置条件。
