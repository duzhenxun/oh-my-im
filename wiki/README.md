# oh-my-im 项目图谱

这是 `oh-my-im` 的可维护 Markdown 图谱。它把仓库中的 README、开发文档、包配置、TypeScript 源码及项目运行说明整理为可回查的结构，不替代代码和真实运行验证。

从 [[maps/系统图谱|系统图谱]] 开始了解组件关系；从 [[topics/入口与运行模式|入口与运行模式]] 区分 `omi`、DWS 和机器人 Stream Mode；从 [[syntheses/消息到回复链路|消息到回复链路]] 查看完整处理流程。

## 使用方式

- 修改前：查看 [[topics/模块边界|模块边界]] 与 [[topics/配置与状态边界|配置与状态边界]]，再回查对应源码。
- 排查监听：从 [[topics/DWS群监听|DWS 群监听]] 进入，注意事件连接不等于真实消息已投递。
- 排查单聊机器人：从 [[topics/机器人Stream模式|机器人 Stream Mode]] 进入，核对本地配置与白名单。
- 增量维护：遵守 [[SCHEMA|Wiki 规范]]，并将新源码/文档作为可追踪来源写入 `sources/`。

当前图谱依据 2026-08-18 的本地仓库检出及 [[sources/项目运行说明|项目运行说明]] 生成；外部 DingTalk、DWS、Codex CLI 和本机进程状态均未在本次生成中执行验证。
